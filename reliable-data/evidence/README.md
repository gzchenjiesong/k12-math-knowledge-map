## 版本与核验边界

本轮资料检索线索提及2025修订版（非用户提供），但本轮未取得并核对相应官方数学正文。2022版和2017年版2020年修订**均不宣称现行最新版或学校现用版**；后续须取得具体修订正文，再对照版本差异。

`section_checked` 只表示所引用位置已经读取；`catalog_only` 只用于实际核过的目录（本轮没有把空入口冒充目录）；`pending` 表示尚未核对。它们不是卡片的 `review`。范围依据不等于题目答案依据，AI读取不等于独立多模型复核或人工签核；本轮未完成后两项。

## 检查与跨机器行为

```sh
node tests/check-sources.js
node tests/check-sources.js --self-test
```

只使用Node内置模块，脚本不联网、不下载、不修改文件。检查67节点集合、来源存在性、固定引用字段、用途与核对枚举、取得事实、章节位置、原件路径以及本地存在原件的字节数/SHA-256。

- `HASH_OK`：本地文件字节数、哈希及PDF文件头匹配登记；不证明作者身份或数学正确性。
- `NOT_PRESENT`：换机器未带gitignored原件；明确报告未做本地哈希复验，不冒充成功，也不因此使所有来源结构失败。
- `HASH_MISMATCH / READ_ERROR`：实际原件不符或读失败，检查失败。读取权限错误不伪装为文件不存在。
- `--self-test`：42项内存变异/边界用例，不改真源与其他文件；覆盖合法日期更新、闰日与非法日期、新增原件、漏节点、悬空引用、错误枚举、假定位、范围冒充答案、原创自证、无原件、哈希篡改等。`updatedAt` 检查真实日历日期，不固定某次执行日期；原件数量按当前登记计算，不锁死四份。

本轮实际运行：`COVERAGE=67/67`、`SCOPE_SECTION_CHECKED=42/67`、`HASH_CHECKED=4`、`NOT_PRESENT=0`、`SELF_TEST=42/42`、`VERDICT=PASSED`。这里的PASS只限追溯契约与字节完整性，不是内容正确或人工核准结论。
