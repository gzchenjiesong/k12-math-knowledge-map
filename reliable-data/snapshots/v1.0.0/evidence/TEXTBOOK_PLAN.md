## 一、定位与边界（必须遵守）

1. **权威层级**：按任务给定顺序，讲义/老师口径第 1 位 → 官方文件第 2 位 → **权威教材第 3 位（可交叉验证）** → 原创讲解第 4 位。教材是训练营总纲，但**不能因此升格为第 1 层**；老师口径仍可由课堂口述 / 家长转述 / 孩子笔记补锚，PDF 替代不了。
2. **核对基准 ≠ 绝对标准**：教材可能存在印刷错误或口径差异。把它当"永不犯错的标准"会把错误直接传给孩子（`SPEC-008`：错误内容危害大于缺失）。
3. **版权红线**（`SPEC-004` / `DSN-005`）：
   - 合规：自有正版纸质书；出版社官网正版 PDF；微信读书、华东师大"帮你学"、京东/当当、公共图书馆数字资源。
   - 禁止：网盘打包、盗版站 PDF、抓取内嵌、分发。
   - 本工具链**只写"书名 + 版次 + 章节/页码"锚点**，不复制作者原创讲解、解析、编排，不把 PDF 原件入库。
4. **AI 不自证**：即便读过正版教材，AI 也不得把条目置为 `verified`。教材交叉验证只能支撑 `pending → checked`；`verified` 必须由人或老师签字（`SPEC-008`）。
5. **下载与存放由使用者操作**：本工具链不代抓官网 PDF。正版 PDF 放本地 `resource_data/books/`（不入库，仅锚点回查）。
