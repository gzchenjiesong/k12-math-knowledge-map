# SPECS · 契约（不可违反的约束与红线）

> 装：违反即错、可被断言检验、跨模块有效、改动成本高的约束与法律 / 政策红线。
> 不装：当前取值、公式细节、设计理由（分别归 `CONFIG.md` / `RULES.md` / `DESIGNS.md`）。
> 引用配置只写 `CNF-NNN`，不写字面值。

### SPEC-001: 文档优先于代码

文档与代码的权威顺序固定为 `IDX-002`。任何改动先改文档并留修订记录，再同步代码；禁止用代码悄悄改变规则。对话 / 模型回答中的临时结论未落文件不生效。违反即为流程事故，按 `IDX-004` 补正。

### SPEC-002: 知识节点基线按学段分层

知识节点是全局主键集合，规模与构成见 `CNF-001`（v2.0.0 起为四层：`primary` / `junior` / `senior` / `olympiad`）。所有视图（来源 / 主题）、专题授课、题型索引、查漏、卡片都必须建立在这同一批节点上，不得遗漏、不得凭空增列。任何节点集合变动必须同时同步 `nodes.js` / `themes.js` / `lectures.js` / `topic_index.js` / `cards.js` 并重跑 `TST-005`、`TST-007`。可检验条件：授课覆盖数 = 主题覆盖数 = 节点总数 = `CNF-001` 分层基线。**修订记录**：v1.0.0 曾规定"恒为 57"；v2.0.0 因纳入小学 4—6 年级（见 `DSN-012`）改为分层基线，节点 ID 一经发布冻结，跨学段衔接关系只能通过 `reliable-data/index/bridges.json` 声明，不得回写旧卡字段（保证旧版哈希可追溯）。

### SPEC-003: 掌握状态唯一数据源

掌握状态只能存于 `apps/miniprogram/utils/store.js` 定义的 `CNF-002` 存储键，取值域为 `CNF-002` 的三态。任何页面、任何视图（含来源视图与主题视图）不得建立第二份状态副本或绕过该层直接读写 storage。可检验条件：全工程仅 `store.js` 出现该存储键，状态值域闭合于三态。

### SPEC-004: 内容原创红线（法律）

所有讲解、例题、自检、题型讲解均须原创编写，依据只能是数学公共知识（定理、公式、通用解题方法、竞赛真题题目本身）。**禁止复制付费教材作者原创的讲解段落、解析文字、编排内容**；禁止抓取、内嵌、分发盗版 PDF。正版数字化渠道见 `DSN-005`。此项为平台 / 法律红线，违反即停止发布。

### SPEC-005: 升学表述政策红线

面向用户的所有表述不得声称「初中奥赛奖项可用于升学」「竞赛结果可作为高考加分」「有竞赛奖即可强基破格」。涉及竞赛学段、招生、加分的口径必须与 `CNF-008` 官方事实一致。此项为政策红线，违反即纠正。

### SPEC-006: 编号只增不减

九套编号（见 `IDX-005`）遵守四条铁律：只增不减、不复用、不重排、修订追加不覆盖正文。作废保留正文并注明替代条目，编号继续占用。可检验条件：`TST-011` 编号连续性 / 跨文件重复 / 失效引用扫描全绿。

### SPEC-007: 授课优先的导航主线

APP 的第一入口必须是授课页，首页主叙事为「先授课 → 再自检 → 后刷题」（见 `DSN-004`）。题型 / 定位 / 图谱均降为辅助与验证层，不得在导航或首页文案上回到「做题反推知识点」的叙事。可检验条件：tabBar 首项与首页首屏文案断言，见 `TST-003`。

### SPEC-008: 内容正确性优先与不自证红线（法律 / 质量）

内容正确性是本项目的第一价值：**错误讲解的危害大于缺失讲解**——孩子会把错误当成知识记住，故宁可少讲、标注「待核实」，不得输出未经核查却宣称正确的内容。三条硬约束：

1. **不得自证**：AI 生成的内容不得由 AI 自身判定为「正确」。结构校验 `validate.js` 与内容校验 `verify_content.js` 只覆盖可机械判定的子集，其 PASS 不等于内容正确（见 `RUL-008`、`CNF-011`）。任何「已校验无误」的表述都属违规。
2. **定理必带条件**：数学定理的适用条件不得省略（费马需 p∤a、欧拉需互素、基本不等式需各项为正、韦达求实根需验 Δ）。条件完整性受 `TST-014` 断言。
3. **存疑可见 + 可反馈**：每条讲解须携带来源与复核状态（`CNF-010`），用户须能标记存疑（`RUL-008`）。隐藏不确定性、不提供反馈入口属违规。

可检验条件：`TST-013`~`TST-015` + `TST-002` + 人工闸门 `VFY-004`。违反即停止交付并修复。
