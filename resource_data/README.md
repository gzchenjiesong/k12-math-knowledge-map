# resource_data · 原始资料区（不入库）

## 职责

存放编制可靠数据源所需的**原始资料**：官方课标原文、竞赛大纲、百科摘录、教材电子书等。

## 为什么不入库

1. **版权**：教材 PDF、付费资料不能进入公开仓库（对应 `SPEC-004` 内容原创红线）。
2. **体积**：PDF / 图片等大文件不适合 Git。
3. **职责**：这里只是「输入素材」，真正要版本化的是 `reliable-data/` 里编制后的卡片与依据锚点。

## 使用约定

- 目录结构：`official/`（教育部课标、竞赛大纲等官方原文）、`wiki/`（百科摘录）、`books/`（教材电子书与书目信息）、`notes/`（讲义摘录、人工笔记）。
- `.gitignore` 已排除本目录全部内容，仅保留 `README.md` 与各子目录 `.gitkeep`。
- **证据链写法**：引用原始资料时，不要复制原文入库，只在 `reliable-data/evidence/` 写「资料名称 + 版本 + 章节/页码」锚点，人工可回到本地原件核对。
- 教材类资料的合法获取与使用由使用者自行负责；本项目不分发任何盗版内容。
