# resource_data · 原始资料区（不入库）

## 职责与版权

存放本地合法取得的原始资料，仅用于阅读与回查。数学讲解和示范题仍由 `reliable-data/` 独立编制，范围依据不等于题解证据。

- `official/`：官方公开数学正文，以及如实标记来源身份的机构转载材料。
- `books/`：合法持有的教材；`notes/`：获准使用的讲义或笔记；`wiki/`：其他待审核资料。目录未存在时不代表已有材料。
- `.gitignore` 排除资料，仅保留本README等明确例外；本轮已用 `git check-ignore` 确认下列4份PDF均被忽略。
- 公开访问不等于开放再分发许可。PDF、扫描图片、提取文本及付费教材内容均不得进入仓库、应用资源或发布包。不删除已有用户资料。
- 联网获取以下官方公开链接已经用户授权；不安装软件，不绕过登录或付费，不访问真实云数据。

## 读取过程与缺口

PDF阅读先按可用Office/PDF技能路由。高中PDF文字提取成功，但公式字形和页脚有错位，因此只登记章节范围，不以提取公式核准答案。义务教育扫描件默认工具失败后，使用已有Python标准库按PDF页树提取内嵌原图并目视核对；没有安装OCR、下载替代软件或更改原PDF。阅读中间产物也只留 `official/` 的独立读取子目录，不入库。

- 2025修订版官方数学正文未取得；不得称2022/2020版本为现行最新版。
- 智慧教育、出版社与专业机构入口已经访问，但没有因此取得具体教材或竞赛大纲正文。
- 9本奥数教材、学校讲义及多数竞赛专题直接依据仍待合法提供。
- 未完成节点定义/题解逐条外部核对、多模型复核或人工签核。
