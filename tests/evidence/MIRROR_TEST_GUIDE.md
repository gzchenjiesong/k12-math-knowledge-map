# MIRROR_TEST_GUIDE：小米手机 → 小米电视 屏幕镜像验证清单

> 日期：2026-11-26
> 家长硬件：手机 HyperOS 4，电视为小米设备（自带投屏 / 共享屏幕）
> 选定路径：M1 系统屏幕镜像（零开发），验证 L1 横屏 + L2 演示模式在大屏上的真实效果

## 0. 关键前提：必须用含横屏改动的代码包

已上传的 `1.0.0` 是 **L1/L2 改动之前**的包。**直接用「预览」扫码打开的是旧版，看不到横屏多栏与演示模式。**

两种拿到新代码的方式：

| 方式 | 操作 | 影响 | 注意 |
|---|---|---|---|
| A 真机调试（推荐先试） | 微信开发者工具 → 真机调试 → 扫码 | 不改已上传版本，不影响审核 | 可能有 vConsole 调试浮层；关掉再投屏 |
| B 上传新开发版 | 工具里上传 `1.0.1` 开发版 → 预览扫码 | 不影响当前审核中的版本（审核快照独立） | 画面干净；后续若要发布需重新提审 |

> 备注：HyperOS 4 已满足「应用投屏」条件（官方要求 HyperOS 3+），若 M1 体验受限于手机常亮/通知弹出，可改试 M2：投屏时选「应用投屏模式」只投微信。

## 1. 连接步骤

1. 手机与电视连**同一个 Wi-Fi**，手机打开蓝牙与 WLAN（HyperConnect 官方要求）。
2. 手机下拉控制中心 → 点「投屏」→ 选择家里的小米电视。
3. 电视端确认连接（首次可能需在电视上同意）。
4. 手机切到横屏（已开 `pageOrientation: auto`，页面会跟随旋转）。
5. 打开小程序 → 进入任一专题详情页。
6. 在导语卡底部点「**演示模式**」→ 用「上一个 / 下一个」翻两页。

## 3. 结果分支

- **全部正常** → M1 可作为当前大屏方案，暂不做 L3。
- **黑屏** → 检查是否用了真机调试浮层；再试 M2 应用投屏或 M3 PDF 分享。
- **布局破版** → 记录具体页面与截图，回项目修断点。
- **手机常亮/通知不可接受** → 切 M2 应用投屏（HyperOS 4 支持），或做 L3 + M4 公网链接让电视独立显示。

## 4. 未验证项

- 电视型号与系统版本尚未提供，画中画（HyperOS 2+）与微信投屏支持情况待确认。
- 电视是否安装 WPS / 浏览器待确认，决定 M3 / M4 是否可直接用。
