# TV PPT 16:9 · 投屏演示页电视适配调研与实现

生成时间：2026-11-26　适用页面：`pages/present/present`　关联决策：M1（小米手机 + 电视系统镜像，手机当遥控器）

## 1. 调研结论：电视端只有 16:9 是主力

调研范围：55 / 65 / 75 / 85 / 100 寸智能电视的主流分辨率与屏幕比例。

| 尺寸 | 主流分辨率 | 屏幕比例 | 2025 中国零售量占比 | 典型观看距离 |
|---|---|---|---|---|
| 75" | 3840×2160（4K UHD） | 16:9 | **24%**（第一大尺寸） | 约 3m |
| 65" | 3840×2160 | 16:9 | 19% | 2.5–3m |
| 55" | 3840×2160 | 16:9 | 18% | 2–2.5m |
| 85" | 3840×2160 | 16:9 | 13% | 3.5m+ |
| 98"/100" | 4K 为主，少量 8K | 16:9 | 合计 3% | 3.5m+ |

关键判断：

1. **4:3 在现代电视已淘汰**——4:3 是显像管老电视比例，55 寸以上智能电视几乎全是 16:9。会遇到 4:3 的是 **iPad 横屏（控制器端）**，不是电视端。因此只做一套 16:9 电视版式，不做 4:3 两套。
2. **4K 是绝对主流**（渗透率 >80%，2025 出货超 4500 万台）；8K 渗透率约 8% 但原生片源稀缺、投屏场景无需考虑。设计按 4K 16:9 一套坐标系即可缩放覆盖所有尺寸。
3. 四个主力尺寸（55/65/75/85）合计 74%，一套 16:9 母版全部覆盖。
4. 数据来源：奥维云网（AVC）2025 彩电市场推总数据、中国电子视像行业协会 2026 选购口径、行业公开报告（4K/8K 渗透率）。

## 2. 实现方案：固定 16:9 画布 + 等比缩放

### 2.1 核心机制

- 画布内部用**固定 1280×720 坐标系**（PPT 逻辑像素），所有版式、字号按此坐标系写死 px。
- 运行时取屏幕可用区域，算出能放下的**最大 16:9 矩形** `(cw, ch)`，居中 letterbox，多出空间留黑边。
- 缩放系数 `deckScale = cw / 1280`，用 `transform: scale()` 从左上角等比放大填满画布框。
- 效果：无论源设备是 16:9（手机横屏）还是 4:3（iPad 横屏），画布永远是标准 16:9，镜像到 16:9 电视正好铺满，不迁就源设备比例。

```js
// present.js onLoad 核心计算
const availW = info.windowWidth;
const availH = info.windowHeight - statusBarH;
const ratio = 1280 / 720;
if (availW / availH >= ratio) { ch = availH; cw = ch * ratio; }
else { cw = availW; ch = cw / ratio; }
const deckScale = cw / 1280;
```

### 2.2 PPT 版式（按 slide.kind 分支）

| kind | 版式 | 视觉 |
|---|---|---|
| cover / end | 居中隆重 | 大标题 + 副标题 + 导语 + 目标标签胶囊 |
| essence | 金句式 | 绿色引号装饰 + 左边框金句卡片，正文 44px |
| method | 编号卡片 | 1/2/3 圆形序号 + 卡片行，正文 36px |
| question | 题纸 | 白底题干卡居中 + 「先独立思考」提示 |
| answer | 解析 | 绿框深绿卡 + 题目回顾小字 |
| recap | 双栏 | 左「易错警示」橙 / 右「概念自检」绿 |

分页保持**先思后答两页**（题干页 + 解析页），每个知识点 5 类页循环。

### 2.3 遥控器交互

- 底部 4 按钮（目录 / 上一页 / 下一页 / 退出），悬浮在 16:9 画布**外**的 letterbox 区域，不遮挡 PPT。
- 翻页后 3.5 秒**自动淡出**，触摸任意处唤醒——电视上大部分时间只有干净的 PPT 画面，接近真实 PPT 播放体验。
- 支持左右滑动翻页、目录浮层跳知识点。

1. 初版画布 padding-top 30px 导致正文 kicker 与顶部信息条重叠 → 改为 78px/54px 上下留白。
2. 方法页 3 条卡片在 720px 画布溢出、第 3 条被页脚压住 → 压缩卡片间距与字号（40→36px），并加 `max-height:100%; overflow:hidden` 兜底。
3. 封面目标标签压页脚、导语第 3 行截断 → 缩小封面字号、导语 clamp 调至 4 行。
4. WXML 字段名笔误 `slide.check` → `slide.checks`，已修正。

## 5. 已知边界与后续

- **系统镜像的固有限制**：手机横屏镜像到电视时，控制条（唤醒态）也会出现在电视画面底部，3.5 秒后淡出。若需电视端完全无控制条，须升级为双端方案（电视独立渲染 + 云同步页码），本轮按 M1 决策不做。
- 内容超长风险：解析最长 242 字、方法最多 4 条（当前数据实测），在 1280×720 内可完整显示；若未来内容显著变长，需按需拆页或缩字号。
- 真机投屏效果待家长按 `MIRROR_TEST_GUIDE.md` 实测（CLI 只能截图模拟器，无法切电视镜像）。
