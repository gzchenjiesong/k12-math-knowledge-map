# 小程序提审清单 v1.0.0（照做版）

生成时间：2026-11-25　适用版本：开发版本 `1.0.0`（见 `UPLOAD_V100.md`）

## 0. 结论先行

提审前需确认「用户隐私保护指引」状态：代码未调用任何微信隐私接口，微信不会标出必填的信息类型，"开发者处理的信息"一栏**保持空即可，不需要勾选任何项**。

重要更正：微信隐私保护指引的可勾选清单里**没有 openid / 用户唯一标识这一项**。openid 由微信平台自动注入（`_openid`），不属于"通过隐私接口收集的用户信息"，官方未将其列入声明范围。此前"勾选 openid 一项"的说法有误，以本节为准。

仍需填写的是：联系方式（邮箱/电话）、信息存储期限、用户权益联系方式等必填项。

## 1. 代码隐私接口扫描结果（已核实）

全量扫描 `apps/miniprogram` 所有 js，实际调用的 wx API 只有这些：

```
wx.cloud  wx.getStorageSync  wx.setStorageSync  wx.removeStorageSync
wx.login（仅注释中出现，非实际调用）  wx.navigateTo  wx.switchTab
wx.setNavigationBarTitle  wx.showModal  wx.showToast  wx.vibrateShort
```

| 隐私接口类别 | 是否使用 | 说明 |
|---|---|---|
| openid / 用户唯一标识 | 不适用（官方清单无此项） | `app.js` 中 `wx.cloud.init({ traceUser: true })` 仅为云开发环境初始化；`_openid` 由云数据库自动注入，不通过任何隐私接口采集，微信隐私保护指引不提供该勾选项 |
| 手机号 / 获取用户信息 / 头像昵称 | 否 | 无 `getPhoneNumber` / `getUserProfile` |
| 位置 / 相册 / 摄像头 / 麦克风 | 否 | 无相关 API |
| 剪贴板 / 扫码 / 蓝牙 / 录音 | 否 | 无相关 API |
| 订阅消息 | 否 | 无 `requestSubscribeMessage` |
| UGC（用户产出内容 publicly 可见） | 否 | 笔记仅存本地 + 可选私有云同步，无公开访问、无分享 |

**结论：微信定义的 20 类可声明信息，本小程序一项都未通过接口采集。因此"开发者处理的信息"保持空，不勾选任何项。** 若后台因某些原因标出了必填项，先核对第 1 节是否与实际一致，按实际标出项填写即可，不要主动添加未使用的项。

## 2. 配置用户隐私保护指引（后台操作）

路径：公众平台 → 设置 → 功能设置 → 用户隐私保护指引（或提审页面内「完善用户隐私保护指引」入口）。

推荐填写（照抄可过审）：

| 字段 | 填写内容 |
|---|---|
| 开发者处理的信息 / 收集的用户信息类型 | **不勾选任何项**，保持空；本小程序未调用任何微信隐私接口，官方清单里也没有 openid 选项 |
| 引导语 / 开发者信息 | 由后台按主体信息自动生成，核对无误即可 |
| 联系方式（用户权益） | 填写可联系到开发者的邮箱，用于用户行使查阅/复制/更正/删除等权利 |
| 信息存储期限 | 选择「实现处理目的所必要的最短时间」或按实际填写；本小程序仅在本地持久化进度与笔记，云端可选同步由用户主动开启 |
| 第三方插件 / SDK | 无（未接入第三方插件） |
| 补充文档 | 可留空 |

要点：隐私指引的核心是**与代码实际一致**——本项目是纯本地离线优先，无接口采集，所以"零勾选"是正确状态。若系统因版本检测标出某个必填项，按标出的项如实填写，不要主动添加未使用的项。

若提审被"用户隐私保护指引未配置/为空"拦截：多数情况是**指引尚未审核生效**或**必填联系方式/存储期限未填**，而非"零勾选"本身；补齐这些必填项并等待指引状态变为「已生效」后再提审。

配置后状态需为「**已生效**」（版本管理 → 审核版本详情页可核验），再提交审核。

## 4. 时机说明

- 提审与备案是**两条独立线**，可并行：代码审核与管局备案互不阻塞，但**备案未完成不能发布**（审核通过也不行）。
- 名称审批与代码审核也是两条线：代码包内界面标题已是「数学阶梯」，后台账号名待审批生效，不影响代码审核本身。
- 因此 **隐私指配置好即可提审，不必等名称/备案**；等审核通过时备案也差不多下来了，最省时间。
- 提审后请勿再变更小程序名称或备案信息（备案订单提交后系统不取最新信息，见 CNF-017）。

## 5. 若被驳回（高频原因对照）

| 驳回提示 | 应对 |
|---|---|
| 未配置/不匹配用户隐私保护指引 | 核对第 1 节实际接口，按第 2 节补齐后**重新提交**（首次驳回后重提约 7 工作日） |
| 类目与实际功能不符 | 已选「教育信息展示」且全为静态内容展示；若仍提示，按站内信具体条款整改，不要申诉硬顶 |
| 页面空白/功能不完整 | 本 app 本地存储、无网络依赖，模拟器四场景已 PASS；如个别页异常附截图说明 |
| 名称/简介问题 | 名称审批生效前可能显示默认名；等生效后重新提审 |

重新提交时在版本说明首行写明「针对 XXX 驳回原因做了 XX 修改」，审核员复核更快。

## 6. 发布（审核通过后）

审核通过**不会自动上线**，需手动：公众平台 → 版本管理 → 审核版本 → 发布。发布前确认备案号已下发，否则会被拦在最后一步。
